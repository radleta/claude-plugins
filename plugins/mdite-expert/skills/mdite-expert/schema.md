# mdite Wiki — Schema

## Page Types
- **Knowledge page**: Core domain content with frontmatter (tags, updated, summary)

## Conventions
- Filenames: kebab-case, descriptive
- Links: standard markdown (`[Page](page.md)`)
- Frontmatter: tags, updated, summary required on all knowledge pages
- Index cap: ~100-150 lines

## Evolution
Review and update this schema after every 10-20 ingests.
