# Diction Precision: The Right Word Over the Approximate Word

McPhee's diction discipline (*Draft No. 4*) rests on a single premise: approximate words signal approximate thinking. When a writer settles for "move" when "trudge" or "glide" is available, the sentence tells the reader less than it should — and the writer probably knows less than they think they do.

## The Dictionary Pass

McPhee describes a practice of not moving on from a word until alternatives have been exhausted — not to find a more impressive synonym, but to find the word that is exactly right. The test is specificity: does this word pick out the exact thing being described, or a class that merely includes it?

The common failure mode: writing stops when an approximately correct word is found. The right practice: treat the approximately correct word as a placeholder and return to it in a dedicated diction pass.

## Specificity Over Impressiveness

The instinct when searching for a "better" word is to find a longer or more formal one. This is the wrong direction. McPhee's discipline pushes toward specificity, which almost always means a concrete, often shorter word:

| Approximate | More exact options |
|-------------|-------------------|
| walked | trudged, strode, shuffled, ambled, lurched |
| said | muttered, announced, conceded, insisted, ventured |
| big | enormous, towering, dense, sprawling, hulking |
| problem | bottleneck, gap, flaw, conflict, ambiguity, impasse |
| improved | doubled, recovered, sharpened, corrected, stabilized |
| used | deployed, consumed, exploited, relied on, borrowed |

The right word is rarely the impressive word. It is the true word.

## Vague Intensifiers as Diction Failure

Zinsser (*On Writing Well*) catalogs a related pattern: using intensifiers (very, extremely, incredibly) in place of a word precise enough to carry its own weight. "Very tired" can almost always become "exhausted." "Extremely cold" can become "brutal" or "frigid." The intensifier is a symptom that the base word is not doing its job.

The test: if an intensifier precedes an adjective, can a single adjective replace the pair? If yes, replace it. If no suitable single word exists, the intensifier may stay — but this is rare.

## Hedges vs. Genuine Uncertainty

Approximate diction often co-occurs with hedging: "somewhat problematic," "a kind of solution," "basically works." These hedges signal one of two things: (a) genuine uncertainty the writer has not resolved, or (b) unexamined approximation. If (a), name the uncertainty directly ("this may fail when the cache is cold"). If (b), find the word that is actually true.

Source: McPhee, *Draft No. 4* (diction chapters); Zinsser, *On Writing Well* (word choice and clutter).

## How to apply

1. Separate the diction pass from the clutter pass — they are distinct tasks that interfere with each other when combined.
2. Read through the draft and flag every placeholder: approximate verbs, vague nouns, intensifier + adjective pairs. Mark them without fixing; do not interrupt reading flow.
3. For each flagged word, consult a thesaurus not for a more impressive word but for the true word. Test each candidate by reading the sentence aloud with it substituted.
4. Apply the specificity test: does this word pick out exactly the thing, or a class that includes the thing? If a class, narrow it.
5. Replace every "very + adjective" and "extremely + adjective" with a single word. Default to the single word; only keep the intensifier if no single word exists.
6. When uncertain what the right word is, notice the uncertainty: it usually signals unresolved thinking about the subject. Resolve the thinking first — the word will follow.
