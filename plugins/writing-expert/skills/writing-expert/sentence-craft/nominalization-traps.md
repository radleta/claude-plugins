# Nominalization Traps: Verb Burial in Abstract Nouns

Pinker's *The Sense of Style* identifies nominalization — converting a verb or adjective into an abstract noun — as one of the most reliable energy-killers in formal prose. The pattern is so common in professional and academic writing that it reads as authoritative, which makes it hard to spot.

## The Pattern

A nominalization buries a living verb inside a dead noun:

| Nominalized | Restored |
|-------------|----------|
| provide assistance | help |
| make an assumption | assume |
| give consideration to | consider |
| reach a conclusion | conclude |
| offer a recommendation | recommend |
| conduct an investigation | investigate |
| achieve an improvement | improve |
| make a decision | decide |
| carry out an analysis | analyze |
| is in violation of | violates |
| take into consideration | consider |
| make reference to | refer to |

The nominalized versions are not wrong. They are inert. The restored versions move.

## Why It Happens

Nominalizations proliferate in formal and technical writing because they sound measured and authoritative. "We conducted a thorough investigation" sounds more official than "we investigated thoroughly." The formality is real; the energy cost is also real. Pinker argues the tradeoff is rarely worth paying.

The pattern traces to academic prose conventions where noun-heavy sentences are equated with rigor. Nouns accumulate; verbs move. Rigor does not require inertia.

## The Diagnostic

A sentence is suffering nominalization when:
- The main verb is a weak support verb: make, have, give, do, provide, conduct, carry out, achieve, offer, reach, take
- The apparent semantic weight sits in a noun ending in -tion, -ment, -ance, -ity, -ness, or -al

Support verb + abstract noun = the nominalization signature. When you find it, the verb is almost always recoverable.

## Active Voice as the Related Recovery

Passive voice and nominalization often co-occur — both hide the agent of the action. Pinker's diagnostic question: who did what to whom? The answer supplies the active sentence and usually eliminates the nominalization in the same move.

Passive voice is legitimate in three cases:
1. The agent is unknown ("the server was restarted")
2. The agent is irrelevant and the receiver deserves the topic position
3. The receiver must open the sentence to connect to the prior sentence's end

Outside these three, restore the agent and the active verb.

Source: Pinker, *The Sense of Style*, chapters on Classic Style and "the web of words."

## How to apply

1. Run a targeted search on any formal draft for the support verbs: make, have, give, do, provide, conduct, carry out, achieve, offer, reach, take.
2. For each hit, inspect the object noun. If it ends in -tion, -ment, -ance, -ity, -ness, or -al, it is almost certainly a nominalized verb.
3. Restore the verb: "make a decision" → "decide"; "provide assistance" → "help"; "conduct an investigation" → "investigate."
4. After restoring the verb, ask who performed the action. If you can name an agent, make the sentence active.
5. Apply the passive-legitimate checklist: unknown agent, irrelevant agent, or receiver-as-topic. If none apply, default to active.
6. Read the before and after aloud: the restored sentence is almost always shorter and cleaner. Use that as confirmation the fix was correct, not as an aesthetic preference.
