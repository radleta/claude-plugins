# Short Assignments: Narrowing Scope to Overcome Process Paralysis

Anne Lamott introduces the "one-inch picture frame" in *Bird by Bird*: when blocked, stop trying to write "the article" or "the essay" and instead write one scene, one moment, one example — whatever fits inside a 1-inch square frame. The full piece is too large to see all at once; the single concrete thing is not.

This is a scope diagnosis, not a quality diagnosis. The shitty-first-draft permission addresses quality anxiety ("it has to be good"). The short-assignment technique addresses scope anxiety ("I have to cover everything"). They often occur together but have different remedies.

The mechanism: a blocked writer is trying to mentally hold the entire piece while also constructing its first sentence. These tasks conflict — the whole cannot be held in working memory while a sentence is being built. Narrowing to a short assignment releases the pressure of the whole by making the local task specific and bounded.

For technical writing: instead of writing "the introduction," write the one concrete example that illustrates the main claim. Instead of "the background section," write the one analogy that explains the core concept. The full structure is still there in the spine, but the immediate job is tiny and finishable.

**Source:** Anne Lamott, *Bird by Bird* (short assignments chapter; one-inch picture frame technique).

## How to apply

1. **When blocked, write down the smallest concrete thing the piece needs.** Not "write the introduction" — "write the 2-sentence story about when the server failed at 3am." Start with that.
2. **Use the spine to find short assignments.** Each spine entry is a bounded task. Pick the entry with the least pressure and write it first; skip the opening entirely until the end.
3. **Give the short assignment a word-count ceiling** (e.g., "write the Redis analogy, max 150 words"). The ceiling makes the task feel completable and prevents scope creep.
4. **Never start with the opening.** The opening is the hardest assignment and the least bounded — it cannot exist until the piece knows itself. Start with the most concrete section (the example, the case study, the step-by-step) and let the opening emerge from what you have already written.
5. **Declare the short assignment complete when it exists,** not when it is good. "Good" is a revision question answered in a later pass.
