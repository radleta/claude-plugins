# Wiki Schema

## Page Types

- **Core discipline**: Three-seal gate doctrine, diagnostic-only protocol, iteration patterns
- **Sub-protocols**: Specific techniques within the verify-fix-loop framework
- **Gotchas**: Counter-intuitive behaviors in manual verification or diagnostic iteration

## Frontmatter

All pages require YAML frontmatter:


## Naming Conventions

- Kebab-case filenames
- No numbering prefixes
- Descriptive (e.g., `diagnostic-only-iter-protocol.md` not `iter5.md`)
